# Case study

Proof that lives on the site. Built only from real results.

## Layout

1. **H1:** the client type and the result with its number ("[Client type]: [result] in [timeframe]").
2. **Summary box:** client type, industry, what was done, timeframe, 2-4 headline numbers. Straight, no jokes.
3. **The situation:** what wasn't working.
4. **What was done and why:** the decisions, in order. This is the part readers (and AI answers) value most.
5. **Results:** a table of real numbers with timeframes.
6. **The client's words:** a real quote if one exists.
7. **Services used:** linked to their pages.
8. **Call to action:** "Want something similar?"

## Rules

- Real numbers only, each with its timeframe. Exact labels: leads aren't customers, pipeline isn't revenue.
- Client named only if it's already public or the owner agrees; otherwise describe them.
- If the work was done with a team or partner, say so.
- Real screenshots and photos only.
- `Article` schema, `BreadcrumbList`. Linked from the case studies index, the service pages it relates to, and the homepage proof section.
