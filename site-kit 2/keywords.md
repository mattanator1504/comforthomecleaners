# Keywords (optional)

Use this only if you want to plan keywords ahead. Leave it empty, or delete it, and the commands work without it.

Add keywords one per line, with an optional note. The build, `/page` and `/blog` take from this list first and remove each keyword once its page is made (it moves to `keywords-used.md`).
